# 🧪 رحلة في عالم حالات المادة

منصة تعليمية تفاعلية باللغة العربية لطلبة **المرحلة الأساسية الدنيا**، تعلّم حالات المادة (الصلبة، السائلة، الغازية) وتحولاتها (الانصهار، التجمد، التبخر، التكاثف) من خلال رحلة علمية فيها شرح صوتي مسجّل، ومحاكاة حيّة للجسيمات، وأنشطة متنوعة، ونظام نقاط ونجوم، واختبار نهائي، وشهادة إنجاز.

## ✨ المزايا

- **خريطة رحلة** من 6 محطات: الصلبة ← السائلة ← الغازية ← تحولات المادة ← النشاط التفاعلي ← التحدي النهائي.
- **محاكاة جسيمات حيّة** (Canvas): جسيمات صلبة تهتز في مكانها، وسائلة تنزلق وتأخذ شكل الوعاء، وغازية تنتشر في كل الوعاء. يمكن تغيير حجم الوعاء وإيقاف الحركة.
- **تجربة الأوعية**: 200 مل من الماء تُسكب في كأس طويل ووعاء عريض ودورق، مع تدريج بالمليلتر وزر لإظهار الجسيمات (العدد نفسه في كل وعاء) وهي تنزلق وتملأ شكل الوعاء.
- **مختبر التحولات**: أسهم دافئة (تسخين) وباردة (تبريد)، ومقياس حرارة، ومحاكاة تُظهر تغيّر حركة الجسيمات وانتظامها.
- **أسئلة متنوعة**: اختيار من متعدد، صح أو خطأ، تصنيف المواد، مطابقة، تحديد نوع التحوّل، وأسئلة تعتمد على الصور.
- **أمثلة تفاعلية**: الضغط على أي مثال يعرض معلومة قصيرة عنه.
- **شريط تنقل سفلي** على الهاتف للانتقال السريع بين المراحل.
- **تغذية راجعة مشجّعة**: لا عقاب على الخطأ في النشاط، مع إعادة المحاولة وزر تلميح.
- **نقاط ونجوم**: الإجابة الصحيحة +10 ونجمة، إكمال نشاط أو مرحلة +20، إكمال جميع المراحل +50.
- **تحدٍّ نهائي** من 8 أسئلة، و**شهادة إنجاز** عند 70% فأكثر، تُحفظ كصورة PNG عالية الدقة (A4 أفقي) أو تُطبع/تُحفظ PDF.
- **RTL بالكامل**، متجاوب مع الهاتف واللوحي والكمبيوتر، يدعم لوحة المفاتيح وقارئات الشاشة، ويحترم إعداد "تقليل الحركة".
- **يعمل بدون إنترنت (PWA)**: بعد الزيارة الأولى تُحفظ ملفات الموقع على الجهاز، ويمكن تثبيته على الشاشة الرئيسية كتطبيق. عند تعديل أي ملف غيّر `VERSION` في `sw.js`، وإذا أضفت ملفًا جديدًا أضفه إلى قائمة `ASSETS` فيه.
- **خلط الخيارات**: يتغيّر ترتيب الخيارات في كل محاولة حتى لا يحفظ الطالب مكان الإجابة.
- **قسم "عن المنصة"** للمعلمين وأولياء الأمور: نتاجات التعلّم، ودليل الاستخدام في الصف، وزر لبدء رحلة جديدة لطالب آخر على الجهاز نفسه.
- **مشاركة احترافية**: صورة ووصف يظهران عند مشاركة الرابط على واتساب ومواقع التواصل، وأيقونة خاصة بالمنصة.
- **بدون مكتبات خارجية**: HTML و CSS و JavaScript (ES Modules) فقط. الخطوط من Google Fonts.

## 🚀 طريقة التشغيل

الموقع يستخدم ES Modules، لذلك يجب فتحه عبر خادم محلي (لن يعمل بالنقر المزدوج على `index.html`).

اختر أي طريقة:

```bash
python3 -m http.server 8080
```

```bash
npx serve .
```

ثم افتح: `http://localhost:8080`

أو استخدم إضافة **Live Server** في VS Code.

## ✏️ إضافة أسئلة جديدة

افتح `src/data/activityQuestions.js` (النشاط) أو `src/data/challengeQuestions.js` (التحدي النهائي)، وأضف كائنًا جديدًا بمعرّف `id` فريد.

**اختيار من متعدد:**
```js
{
  id: 'a9',
  type: 'mcq',
  prompt: 'أي من الآتي غاز؟',
  options: [
    { text: 'الهواء', emoji: '🌬️', correct: true },
    { text: 'الحجر', emoji: '🪨' },
  ],
  hint: 'فكّر في شيء لا نراه لكنه يملأ المكان.',
  explain: 'الهواء غاز ينتشر ليملأ المكان.',
}
```

**صح أو خطأ:** `{ id, type: 'truefalse', prompt, answer: true }`

**تحديد نوع التحوّل:** مثل `mcq` مع `type: 'process'` و `visual: '🧊 ⬅ 💧'`

**سؤال بالصور:** أضف `image` و `imageAlt` لكل خيار.

**تصنيف:** `{ type: 'classify', items: [{ text: 'الحجر', emoji: '🪨', bin: 'solid' }] }` (bin: `solid` أو `liquid` أو `gas`)

**مطابقة:** `{ type: 'match', pairs: [{ left: { text: 'صلبة', emoji: '🧊' }, right: { text: 'تهتز في مكانها' } }] }`

> ملاحظة: التحدي النهائي يدعم الأنواع `mcq` و `process` و `truefalse` (محاولة واحدة لكل سؤال). وتتغيّر الدرجة الكاملة تلقائيًا حسب عدد الأسئلة.

لتعديل نصوص الدروس أو الأمثلة أو أسئلة "تحقّق من فهمك": `src/data/states.js` و `src/data/transitions.js`.
- `checks`: مصفوفة أسئلة التحقق في نهاية كل حالة (تكتمل المرحلة عند الإجابة عن جميعها).
- `examples[].fact`: الجملة التي تظهر عند ضغط الطالب على المثال.
لتعديل قيم النقاط أو نسبة الشهادة: `src/data/config.js`.

## 🌐 النشر على GitHub Pages

1. المشروع مرفوع على: https://github.com/maha90-ops/States-of-Matter
2. في المستودع: **Settings ← Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة تقريبًا يصبح الموقع متاحًا على:
   `https://maha90-ops.github.io/States-of-Matter/`

جميع المسارات في المشروع نسبية، والتنقل يعتمد على الروابط (`#solid`)، لذلك يعمل الموقع على GitHub Pages دون أي إعداد إضافي. ملف `.nojekyll` موجود لضمان نشر الملفات كما هي.
